# حصر ترجمة نصوص الواجهات

تاريخ المراجعة: 2026-10-15.

شملت التعديلات 267 موضع استدعاء للترجمة في 45 ملف واجهة. أُضيف قاموس مشترك للعناوين والحقول والرسائل، مع المحافظة على الواجهة الإنجليزية. بعض الاستدعاءات تترجم أكثر من نص حسب الحالة.

## النطاق

- نماذج التدريب والمحاضرات: العناوين والحقول والحالات والحفظ والإلغاء والظهور للعامة والمواعيد.
- اعتماد الخبراء: الطلبات والبيانات الشخصية والأكاديمية والمهنية والمرفقات وأزرار الاعتماد.
- صفحات حسابات الخبير والفرد وولي الأمر والمؤسسة.
- إعدادات المختصين والقوائم المرجعية والمدفوعات والتخصيصات وخيارات الاستبيان.
- معاينات الخطط والتقارير والوسائط والاستبيانات والاختيار من متعدد.
- تسجيل الدخول وإعادة تعيين كلمة المرور ورسائل التحقق والتنقل والتذييل وتسميات إتاحة الوصول.
- أسماء الأشهر وأيام الأسبوع وأزرار التنقل في منتقي التاريخ، واتجاه نماذج التدريب والمحاضرات.

## التحقق وحدود الحصر

- `npm run audit:translations`: لا توجد نصوص إنجليزية ثابتة غير مستثناة في عقد JSX وخصائص التسميات التي يفحصها البرنامج. هذا فحص مساعد، ولا يثبت تغطية كل نص يولده الخادم أو قاعدة البيانات.
- `npm run test:localization`: أربعة اختبارات عرض تشمل اللغتين، اتجاه النموذج، تسميات الإجراءات، والمحافظة على البيانات المدخلة.
- `npm run typecheck` و`npm run build`: نجح فحص الأنواع وبناء الإنتاج.
- فحص المتصفح: ظهرت تسميات النموذجين بالعربية والإنجليزية، وخيارات طريقة الحضور بالعربية. أُغلقت جلسة الفحص بعد ظهور رسالة تعطل Chrome؛ لم يُستكمل فحص جميع الصفحات بصريًا.
- فحص ESLint للملفات المعدلة: لا أخطاء؛ توجد تحذيرات مسبقة عن الصور والمتغيرات غير المستخدمة.
- لم تُترجم أسماء الأشخاص أو محتوى البرامج أو البيانات المخزنة مثل HEALTH AR؛ هذه بيانات يحررها المستخدم وليست تسميات واجهة.
- أُبقيت الرموز التقنية والروابط والبريد وأمثلة المسارات واختصار DSC، والنص الإنجليزي داخل فرع العرض الإنجليزي في الصفحة الرئيسية.
- نصوص منتقي الملفات والوقت الأصلية التي يعرضها المتصفح نفسه تعتمد على لغة المتصفح ونظام التشغيل.

## إعادة الحصر

شغّل `npm run audit:translations` لعرض النصوص الإنجليزية الثابتة المرشحة للمراجعة، أو `node tools/audit-ui-translations.mjs --json` للحصول على حصر الاستدعاءات والملفات والأسطر بصيغة JSON.
