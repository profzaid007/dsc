# Case documents

Every case detail screen has a Documents section (a Documents tab for clients and administrators). Allocated experts can add a file with a document title. The case owner, currently allocated experts and administrators with cases.read permission may view/download documents. Administrators with cases.create permission can also upload. Clients cannot upload through the document API. Files are protected, at most 10 MiB, with the same permitted formats as message attachments.

An expert receiving a client message can choose Save to case documents beside an attachment, either in Case messages or the inbox. The server verifies current allocation, that the message belongs to this case, that the case owner sent it to this expert, and that the filename is one of the message attachments. It copies the actual file through PocketBase's storage filesystem into a protected case_documents record; no browser re-upload, public URL or local-only storage path is used. It records uploaded_by, source_message and source_filename. Repeated requests reuse the same document; a unique index prevents duplicates. The copied file is independent of the source message attachment. Users cannot edit or delete documents or forge provenance through the record API.
